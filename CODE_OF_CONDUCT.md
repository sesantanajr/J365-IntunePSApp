# Code of conduct

*Português: [abaixo](#código-de-conduta).*

This project wants to be a friendly place for IT professionals of every experience level.

- Be respectful and assume good intentions. Disagree with ideas, not with people.
- No harassment, insults, discrimination or personal attacks of any kind.
- Keep discussions about the project: packaging, Intune, PSAppDeployToolkit, the code and the documentation.
- Do not post confidential information (tenant names, internal URLs, licence keys, logs with personal data). Remove them from logs before sharing.
- Questions in English or in Portuguese are equally welcome.

Maintainers may edit or remove comments, issues and contributions that do not follow these rules, and may block repeat offenders.

To report a problem privately, use GitHub's *Report content* option on the comment or contact the maintainer through the profile linked in the README.

# Código de conduta

Este projeto quer ser um lugar acolhedor para profissionais de TI de qualquer nível de experiência.

- Seja respeitoso e presuma boas intenções. Discorde das ideias, não das pessoas.
- Nada de assédio, ofensas, discriminação ou ataques pessoais de qualquer tipo.
- Mantenha as conversas sobre o projeto: empacotamento, Intune, PSAppDeployToolkit, o código e a documentação.
- Não publique informações confidenciais (nomes de locatários, endereços internos, chaves de licença, logs com dados pessoais). Remova-as dos logs antes de compartilhar.
- Perguntas em português ou em inglês são igualmente bem-vindas.

Os mantenedores podem editar ou remover comentários, issues e contribuições que não sigam estas regras e bloquear quem insistir.

Para relatar um problema de forma privada, use a opção *Report content* do GitHub no comentário ou fale com o mantenedor pelo perfil indicado no README.
